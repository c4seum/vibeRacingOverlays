vibeRacingOverlays - lightweight iRacing overlays
=================================================

Portable version: no installation needed. Put vibeRacingOverlays.exe in any folder and start it.
(Prefer a normal installation? Use vibeRacingOverlays-Setup-<version>.exe instead.)

Requirements
- Windows 10 or 11, 64-bit. Nothing else to install.
- iRacing in windowed or borderless mode, so the overlays can be drawn on top of it.

Getting started
- Without iRacing running, the app shows a demo race, so you can set up your widgets straight away.
- Widgets: Standings, Relative and Fuel calculator. Add more with "+ Add".
- Edit layout (Ctrl+Shift+E): drag widgets to move them, and use the mouse wheel over a widget to resize it.
- Show/hide all widgets: Ctrl+Shift+H.   Next layout: Ctrl+Shift+L.
- Layouts, presets and settings are stored in %APPDATA%\vibeRacingOverlays.

Windows SmartScreen
The app isn't code-signed, so Windows may show "Windows protected your PC" the first time.
Click "More info" and then "Run anyway".
